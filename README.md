# Freebuff Agent Team Template

Master template repository for a 6-role agent company (`@ceo`, `@cmo`, `@cto`, `@seo-expert`, `@designer`, `@coding-expert`).

## Deploy to a Single Project
Copy `agents/` into the project root as `.agents/`:
```bash
mkdir -p /path/to/project/.agents
cp -rn ~/freebuff-team/agents/* /path/to/project/.agents/
